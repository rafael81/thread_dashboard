# 과즙루피 댓글 감독 검수

2026-10-28 사용자는 “앞으로 댓글 달리면 너도 직접 관여해서 검수하고 개선하던지 삭제하던지해”라고 지시했다. 이 권한은 @terafabXai의 자동 댓글·대댓글에 대한 직접 검수, 부적합 댓글 삭제, 필요한 재작성과 재검수에 한정한다. 타인의 댓글이나 원글, 승인된 이미지 사연의 본편/후속 이미지 게시물을 삭제할 권한으로 확대하지 않는다.

2026-10-28 사용자가 “별도 검수 종료”를 지시하여 이 채팅의 10분 주기 Codex 별도 감독 검수를 종료했다. 자동화 `automation`은 PAUSED 상태로 두며 사용자가 다시 요청하기 전에는 별도 감독·삭제를 재개하지 않는다. 댓글 작성 파이프라인의 Codex 원문·미디어 문맥 확인과 게시 전 검수는 유지한다. 아래 절차와 기존 검수·삭제·보류 기록은 보존한다. 프로젝트 AGENTS.md와 로컬 memory를 먼저 확인한다. `.data/terafabx-automation-state.json`의 commentHistory, ownPostReplyHistory, homeVerifiedCommentHistory에서 게시 결과를 수집하고 `.data/comment-supervision-state.json`에 검수한 reply status ID와 판정·시각을 기록해 중복 조치를 피한다. 첫 실행은 최근 2시간의 미검수 댓글을 먼저 확인한다. 매 실행 최대 10건을 처리하고 밀린 항목은 다음 실행에서 이어간다.

검수는 이전 자동 점수나 생성 요약을 정답으로 믿지 않고 직접 한다. 실제 대상 원글, 인용 원문, 대화의 부모 관계, 모든 사진과 이미지 속 글자, 영상의 연속 프레임·자막·로컬 음성 전사를 확인한다. 원본 재생·청취와 프레임/기계 전사 기반 분석을 구분하고 확인하지 못한 사실은 판단 근거로 쓰지 않는다. 인용글에 그 인물의 과거 보도에 대한 반감이 있는데 이름 자체가 우스운 것처럼 해석하는 오류를 주의한다. “기자 이름 보고 웃는 거 웃기네” 같은 원문 반복·빈 메타 반응은 부적합이다.

원문이 “정답은 댓글”처럼 작성자의 후속 답글을 가리키면 실제 정답 댓글까지 확인한다. 자동 검수 원자료에 그 답글이 없으면 `context_complete=false`로 보류한다. 일반적인 화면 구성 설명을 질문의 답으로 대신하지 않는다. 대화 API가 일부만 수집됐으면 전체 수집 완료라고 기록하지 않으며, 확보한 작성자 답글과 정확한 부모 status ID를 근거로 구분한다.

명시적 후속 안내가 없어도 미해결 서사나 원인 불명의 속보 질문은 작성자의 후속 설명을 확인한다. 중첩 답글의 설명은 중간 부모 댓글이 대상 원글에 연결되는지도 검증한다. “식량 비축 권고, 대체 왜”에 “갑자기 식량 비축이라니 무슨 일이래요”처럼 같은 놀람과 질문만 반복하는 댓글은 통과시키지 않는다. 뉴스 영상 썸네일의 속보·비상 문구나 상대 시간만으로 새로운 위기를 확정하지 않는다. 일반 재난 대비 안내나 자연스러운 인사·감사·공감 자체를 금지하는 규칙은 아니다.

오늘·내일·어제 같은 상대 날짜는 원문과 댓글 게시 시각을 Asia/Seoul 날짜로 대조한다. 어젯밤의 “내일” 예보를 다음 날 아침 댓글에서도 “내일”이라고 옮기면 대상일이 하루 밀린다. 대상 절대 날짜를 보존하거나 날짜를 빼고 원문 예보에 대한 반응임을 명확히 한다. 캡처의 실제 예보 대상일을 확인하지 못했다면 현재 예보라고 확정하지 않는다.

원문 의도, 글쓴이/독자 관점, 사실 근거, 자연스러움, 반복성, 조롱·주제 제외 정책을 확인해 keep, delete, rewrite를 판정한다. 분명한 문맥 오류·환각·부적합한 조롱·빈 반복 댓글은 삭제한다. 판단이 불확실하면 삭제하지 않고 보류한다. 삭제 전에 headed Chrome 9224의 지정 과즙루피 Profile 1에서 @terafabXai 계정과 삭제할 댓글의 작성자·정확한 URL을 확인한다.

삭제는 로컬 서버 `POST /api/terafabx/comment-supervision`에 `action=delete`, 정확한 `replyUrl`, 구체적인 `reason`을 전달한다. 이 API는 기록된 자동댓글만 삭제하고 X UI에서 결과를 확인하며 삭제 이력과 원래 target을 남긴다. 삭제한 댓글을 대기열로 되돌리거나 중복으로 재게시하지 않는다. 원글의 맥락상 댓글을 달지 않는 편이 적절하면 삭제로 끝낸다. 재작성할 가치가 있으면 Gemini가 새 문장을 작성하도록 하고 Codex가 원자료와 다시 검수한다. 기존 중복 방지를 임의로 지워 대체 댓글을 게시하지 않는다. 대체 게시 지원이 없는 경우 검수된 수정안을 기록하고 유지보수 작업으로 명확히 남긴다.

반복되는 원인을 발견하면 관련 프롬프트·게이트를 수정하고 의미 있는 회귀 검증을 추가한다. 게시 경로를 바꾸면 AGENTS.md의 실제 X E2E 요건을 지킨다. 새 댓글이 없는 동안에도 코드 개선을 위해 무관한 댓글을 시험 게시하지 않는다. 검수·삭제·보류·실패 근거는 `.data/comment-supervision.jsonl` 및 감독 체크포인트에 보존한다.

IPO·상장 일정과 예상 기업가치·공모가 목록의 금액 규모에 감탄하는 댓글도 금융 가격 반응으로 제외한다. 투자 조언이 없다는 이유로 통과시키지 않는다. 반대로 팔로워·조회 수·음식 가격이나 자영업자의 손님 방문 감사 자체를 금융·홍보로 분류하지 않는다. 이 경계의 회귀 검증은 실제 금융 목록 차단과 일반 감사 글 통과를 함께 확인한다.

2026-10-28 사용자 답변 “신상품·예약 소개 글도 모두 제외”에 따라, 일반 이용자가 여러 브랜드 신상품·한정예약 일정을 모은 소비자 소식도 자동 댓글 대상에서 제외한다. 판매자 계정·유료광고·구매 링크가 아니라는 이유로 예외를 두지 않는다. 신상품·예약 소개와 무관한 사용 후기·식사 사진·교육 내용까지 물건이 있다는 이유로 확대하지 않는다.

보류는 검수 완료가 아니다. `reviewed`에 시도 기록을 남기더라도 `pending`에 댓글 URL·미확인 사항·다음 확인 방법을 함께 남겨 다음 실행에서 다시 확인한다. 수동 음성 전사에도 `-l auto` 또는 확인된 언어를 명시한다. 음악 태그만 나온 전사가 화면의 대사 자막과 어긋나면 언어를 바로잡아 재전사하고, 노래 가사나 발화가 여전히 불명확하면 음성을 이해했다고 기록하지 않는다.

서버가 status ID·본문을 대조해 수집한 API 원자료의 첨부 목록이 모두 비어 있으면 텍스트 전용 검수다. 이 경우 로컬 이미지·영상 파일이 없다는 사실은 미디어 누락이 아니다. 알려진 첨부나 인용 문맥의 누락이 있으면 계속 보류한다.

자동 게시 보류 파일 `.data/comment-publication-hold.json`이 있으면 자동 게시를 재개하지 말고 사유를 확인해 필요한 수정과 실검증을 완료한 뒤에만 해제한다. 미해결 문제가 있으면 보류 사실을 사용자에게 알린다.
