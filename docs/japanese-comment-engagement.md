# 일본어 활동 계정 자동댓글

사용자 승인: 2026-10-31 “팔로우, 팔로워 중에 일본계정 미리 식별해두고 자동댓글로 인게이지먼트”. 국적이나 민족을 추정하지 않고 공개 프로필과 최근 원글의 **활동 언어**를 기록한다.

최신 언어 지시: 2026-10-31 “일본사람 댓글 한글로 달아”. 일본어 원글도 한국어 댓글을 작성한다. `sourceLanguage`는 대상 판별, `replyLanguage`는 한국어 출력 기준이며 기존 일본어 미게시 초안은 원문 검수부터 다시 생성한다.

- 목록: `.data/comment-language-accounts.json`. 팔로잉/팔로워를 핸들 기준으로 합치고 양쪽 관계를 각각 보존한다. 이름·지역·한자만으로 일본어 계정으로 분류하지 않는다. 일본어 자기소개 또는 최근 일본어 원글 2개를 근거로 삼는다.
- 관계 목록을 6시간마다 다시 읽는다. 실패·불완전 페이지는 이전 관계를 지우지 않으며 30분 후 재시도한다. 관계/언어 근거가 7일 넘었거나 비공개 계정이면 일본어 댓글 대상에서 제외한다.
- 기존 팔로잉 순환 탐색에 일본어 계정 12개와 언어 미확인 팔로워 전용 계정 6개의 최근 24시간 원글 탐색을 더한다. 일본어 원글의 의미와 미디어를 확인한 뒤 한국어 댓글을 생성한다.
- 일본어 후보와 한국어 후보를 1:3 순서로 섞되, 적합한 후보가 없으면 비율을 억지로 채우지 않는다. 총 댓글 상한·작성자별 상한·게시 간격은 기존 값을 유지한다. 개인 파란 체크·원글 전용·중복 방지·미디어 검증·독립 심사도 유지한다.
- 한국어 댓글은 최대45자, 원문의 구체 상황에 맞는 짧은 대화체. 범용 인사, 맞팔 요구, 경험 꾸미기, 홍보·출시예약·정치·차별·인신공격·의료/투자 조언은 제외한다. 원문 번역문 대신 자연스러운 한국어 반응을 쓰며 일본어를 병기하지 않는다.
- 대상 등록만으로 게시하지 않는다. 실제 원문/미디어 확인 → Gemini 한국어 작성 → 독립 최종 심사 → `homeVerified` 9340 계정/락 검증 → 기존 X 댓글 게시/영수증 순서를 따른다. 게시 직전에도 언어·근거 유효기간을 검사한다.
- 자기 글 아래 자동 대댓글 경로는 이 변경 대상이 아니다. 타인 글에 댓글 성공 후 기존 네이티브 재게시 정책은 그대로 적용한다.

조회: `node scripts/comment-language-accounts.cjs status`

즉시 관계 재확인: `node scripts/comment-language-accounts.cjs sync`

후보 조회(게시 없음): `node scripts/comment-language-accounts.cjs collect`

운영 상태 API: `/api/discovery/home-verified-dashboard`의 `status.languageAccounts`.

2026-10-31 한국어 전환 전의 최초 실게시 기록이다. [일본어 댓글](https://x.com/terafabXai/status/2116384019726352571)의 작성 계정, 정확한 본문, 부모 ID `2116050032814383238`을 실제 X 화면·TweetDetail 응답·게시 경로의 관계 검증으로 확인했다. 대시보드 게시 타임라인에도 반영됐다. 검증 기록은 위 폴더의 `final-verification.json`, 관련 테스트는 84개 통과다.
